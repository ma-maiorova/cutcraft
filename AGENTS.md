# CutCraft
Учебный Python-проект. Не подмешивать рабочие заметки Tracker/Arcadia.
Сначала прочитать README.md и docs/CONTRACTS.md.
Сохранять интерфейсы модулей и формат 1.0; изменения контрактов согласовать командой.
Реальные и демонстрационные режимы различать явно. Заглушки не выдавать за вызовы LLM или анализ изображения.
Не коммитить ключи, реальные .env и пользовательские видео. Не удалять Java-шаблон/настройки IDEA без задачи.
При изменениях проверять `python3 -m unittest discover -s tests -v` и демо.

## Проверка перед PR

Для проверки готовности изменения используй `.agents/skills/cutcraft-pr-preflight/SKILL.md`. Skill проверяет diff, тесты, демо, контракты и отсутствие секретов в изменении; сам по себе не разрешает публикацию или merge.
