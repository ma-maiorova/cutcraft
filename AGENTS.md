# CutCraft
Учебный Python-проект. Не подмешивать рабочие заметки Tracker/Arcadia.
Сначала прочитать README.md и docs/CONTRACTS.md.
Сохранять интерфейсы модулей и формат 1.0; изменения контрактов согласовать командой.
Реальные и демонстрационные режимы различать явно. Заглушки не выдавать за вызовы LLM или анализ изображения.
Не коммитить ключи, реальные .env и пользовательские видео. Не удалять Java-шаблон/настройки IDEA без задачи.
При изменениях проверять `python3 -m unittest discover -s tests -v` и демо.


## Проектные skills

- `.agents/skills/cutcraft-adr/SKILL.md` — создание и пересмотр архитектурных решений. Использовать при работе над ADR или существенным архитектурным выбором.
- `.agents/skills/cutcraft-contracts/SKILL.md` — изменения каталога, плана и замечаний: JSON Schema, runtime, примеры и совместимость.

Для Codex skills хранятся в репозитории под `.agents/skills/`. Если другой coding-agent не обнаруживает этот каталог автоматически, открыть нужный SKILL.md явно. Эти инструкции предназначены для разработки; они не являются runtime-ролями монтажёра и критика. Runtime-инструкции лежат в `prompts/`.
