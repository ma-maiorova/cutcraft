## Видео

- «Подтверждения Большого взрыва – Борис Штерн | Лекции по астрофизике | Научпоп», канал НаукаPRO, YouTube: https://www.youtube.com/watch?v=8qWEW1nT4h8
- Длительность 3:11, русский язык. Лицензия стандартная YouTube, не открытая: используем только для учебной демонстрации в приватном репозитории.
- Видео в Git не хранится. Скачать для пересборки или просмотра:
  `yt-dlp -f "bv*[height<=720][ext=mp4]+ba[ext=m4a]" --merge-output-format mp4 -o shtern_big_bang.mp4 https://www.youtube.com/watch?v=8qWEW1nT4h8`

## Как получены данные

1. **Транскрипт:** `faster-whisper` 1.2.1, модель `large-v3-turbo`, `language="ru"`, пословные таймкоды, VAD, CPU int8. Полный результат с таймкодами каждого слова — `data/transcript.json` (сырой вывод Whisper до ручных правок); по нему `scripts/render_short.py` синхронизирует субтитры.
2. **Сегменты:** 15 фрагментов по 4–16 секунд покрывают всю речь Штерна (136 с из 191; не вошли заставки, реплики интервьюера и вводные вроде «сейчас скажу, когда…»). Границы проходят по паузам между словами: ни одно слово не обрезано. Каждый фрагмент — законченная мысль.
3. **Текст сегмента:** слова Whisper внутри `[start, end]` без пересказа. Слова-паразиты и запинки Whisper убрал сам; смысловые слова (цифры, имена, «не», «только», «хотя») совпадают с речью.
4. **Кадры:** JPEG 768 px (`ffmpeg -ss <t> -frames:v 1 -vf scale=768:-2 -q:v 3`). Один кадр из середины сегмента. Если внутри сегмента картинка на экране меняется (s1, s3, s14), добавлен второй кадр, чтобы были видны оба изображения.
5. **Проверки:** `validate_catalog` и `resolve_frames` проходят, тесты проходят, `python3 main.py --demo` возвращает `demo_accepted`.

- Сверены на слух 15.10.2026: s1, s2, s3, s5, s7, s10, s14, s15.
- Ручные исправления: в s1 Whisper распознал «13,8 миллиона лет», в речи — «13,8 миллиарда лет»; в s6 «неодородности» исправлено на «неоднородности».
- s5: формулировка спикера сохранена как есть — «такие как реликтовые излучения».

## Известные особенности

- Речь разговорная: s2 начинается с «Ну, то есть», s5 и s15 — с «Дальше…», s6 — с «И дальше…». Смысл каждого фрагмента от этого не зависит.
- s12 начинается с «Это особенность» — она объясняет предсказание из s11; самостоятельно s12 понятна хуже, лучше брать вместе с s11.
- s14 начинается со слова «была»: служебное «Потому что» перед ним отрезано, потому что оно ссылается на предыдущую фразу. «Это стало ясно» внутри s14 относится к теории Хойла из того же сегмента.
- Транскрипт автоматический; при неточности распознавания проверка подписей опирается на исправленный текст каталога, а не на звук.

## Кандидаты в контрольный дефект

- **Кадр не соответствует подписи:** подпись про карту реликтового излучения на s5, s8 или s10 — в кадре только спикер. Для сравнения правильная пара — s14, где карта есть на втором кадре.
- **Потеря оговорки:** подпись «Теорию стационарной Вселенной окончательно отвергли» на s15 — в источнике «Хотя продолжали».
- **Искажение цифры:** подпись «Большой взрыв был 13,8 миллиона лет назад» на s1.

## Ограничения

Один–два стоп-кадра на сегмент; звук и движение не анализируются. Транскрипт сверен вручную по смыслу, слова-паразиты не сохраняются.
