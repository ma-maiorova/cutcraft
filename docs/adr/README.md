# Архитектурные решения

ADR фиксирует существенный выбор: его контекст, решение и последствия. Текущее устройство и команды запуска описываются в README и контрактах; ADR объясняет причины выбора.

## Реестр

| ADR | Решение | Статус |
|---|---|---|
| [0001](0001-storyboard-workflow.md) | Раскадровка и ограниченный workflow из двух ролей | Принято для MVP |
| [0002](0002-json-contracts.md) | Общие JSON-контракты и отдельная техническая валидация | Принято для MVP |
| [0003](0003-local-openrouter-free.md) | Локальное приложение и бесплатные модели OpenRouter | Принято для MVP |
| [0004](0004-multimodal-reviewer.md) | Мультимодальный критик: кадры base64 в одном запросе, только растровые форматы | Принято для MVP |
| [0005](0005-single-container.md) | Один контейнер и одноразовый Compose-сервис для локального workflow | Принято для MVP, часть про видео заменена ADR-0006 |
| [0006](0006-shorts-in-container.md) | Сборка shorts в контейнере после живого запуска | Предложено |

Статус ADR означает выбор архитектуры, а не готовность кода. Что реально работает, показывают README и папка `docs/evidence/`. Первые четыре решения проверены полным циклом на реальном видео 15 октября. ADR-0005 и ADR-0006 проверены 16 октября: сборка образа, тесты внутри него и живой запуск через Compose с готовым видео на выходе.

## Как вести

- Создавать ADR, если решение меняет интерфейсы между модулями, способ запуска, выбор провайдера, стоимость или границы MVP и имеет разумные альтернативы.
- Использовать [шаблон](TEMPLATE.md), следующий номер и короткое имя файла. Обычно достаточно одной страницы.
- Новое решение сначала помечать «Предложено» и обсуждать в соответствующем PR; после согласования — «Принято».
- При пересмотре принятого решения создавать новый ADR, старый отмечать «Заменено ADR-NNNN». Опечатки и ссылки можно исправлять на месте.
- Не создавать ADR на каждую функцию, изменение prompt, баг или замену конкретного бесплатного model ID при прежних требованиях к модели.
- Задачи и личную подготовку к защите не включать. Ключи, токены и закрытые рабочие материалы не сохранять.
