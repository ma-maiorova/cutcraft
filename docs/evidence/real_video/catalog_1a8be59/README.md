# Снимок каталога 1a8be59

Каталог и кадры, на которых записаны сохранённые живые прогоны [`final/`](../final/) и [`revision/`](../revision/).

`catalog.json` — точная копия `data/catalog.json` из коммита `1a8be59` (8 фрагментов). Позже каталог расширили до 15 фрагментов и перенумеровали. Часть файлов с прежними именами теперь показывает другие моменты видео: например, `frames/s5.jpg` и `frames/s8.jpg`.

В `frames/` лежат кадры из того же коммита, но только для фрагментов, вошедших в планы этих прогонов: s1, s2, s5, s8. Они побайтно совпадают с кадрами, встроенными в исходные `report.html` прогонов.

Снимок нужен `render.py`, чтобы перестроенные отчёты (`python3 render.py …`, `python3 scripts/demo.py`) показывали кадры самих прогонов. Отчёт берёт кадр отсюда, только если фрагмент совпадает с сохранённым в `input.json` прогона. Новые запуски этот каталог не используют. Запускать на нём `main.py` нельзя: кадров остальных фрагментов здесь нет.
