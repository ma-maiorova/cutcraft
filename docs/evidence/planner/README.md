# Проверка реального монтажёра

15 октября 2026. Провайдер — OpenRouter, модель `dots-studio/dots-3-note-preview:free`.

Два реальных запроса: создание плана и исправление контрольного дефекта. Проверка прошла, см. result.json. Полный цикл с агентом-критиком здесь НЕ проверяется.

- `initial.json` — первоначальный ответ модели после технической валидации.
- `controlled_defect.json` — копия плана со специально внесённой неподтверждённой подписью первой сцены.
- `manual_review.json` — заранее подготовленное контрольное замечание; НЕ ответ агента Галима.
- `revised.json` — реальный ответ модели при исправлении; подпись заменена на указанную цитату, принятые сцены сохранены.
- `result.json` — время, модель, статус и ограничения проверки.

Источник — неизменный `examples/catalog.json`: синтетический транскрипт и условные картинки. Реальное видео и мультимодальный критик ещё нужны для командной приёмки.

Воспроизведение (два запроса, требуется локальный ключ):

```bash
TEXT_MODEL_NAME=dots-studio/dots-3-note-preview:free python3 scripts/check_planner_live.py
```

Доступность бесплатной модели не гарантируется. Ранее другие модели отвечали 429; один из пробных нестрогих ответов был отклонён контрактом. Не делать вывод о надёжности по одному успешному примеру. Ключи и приватные данные в evidence не сохранены.
