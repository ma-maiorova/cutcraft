# CutCraft — каркас MVP

Два агентных модуля готовят и проверяют монтажный план. Вход — подготовленный каталог одного видео, выход — три сцены на 20–30 секунд и HTML с историей исправления.

## Быстрый запуск

Python 3.10+. Демонстрация использует только стандартную библиотеку, API и установка пакетов не нужны.

```bash
python3 main.py --demo
python3 -m unittest discover -s tests -v
```

Открыть напечатанный путь `output/.../report.html`. Он содержит картинки внутри файла и открывается без сервера.
Каждый запуск создаёт отдельную папку. Существующая папка `--out` не перезаписывается.

**Демо — не работающие LLM-агенты:** ответы фиксированы, ошибка внесена специально, картинки — условные SVG-карточки, а не настоящие стоп-кадры. Демо показывает контракт, цикл и интерфейс. Без `--demo` модули явно сообщают, что модели ещё не подключены.

## Контракт

См. `docs/CONTRACTS.md`, `contracts.py` и примеры. Общая `schema_version: "1.0"`.
Каталог содержит 6 кандидатов. План — ровно 3 сцены. Время — секунды исходного видео.
Проверяющий оценивает каждую сцену, возврат всех `accept` означает принятие. Одно исправление и повторная проверка; затем ручной просмотр при оставшихся замечаниях.
`source_quote` проверяется как подстрока транскрипта; правдивость подписи и визуальное соответствие проверяет модель/человек.

## Подключение моделей

1. Команда выбирает провайдеров и реальные имена моделей.
2. Добавить нужный SDK и зафиксировать зависимости. Сейчас SDK нет.
3. В planner/reviewer заменить `NotImplementedError` реальным вызовом API; интерфейсы сохранить.
4. Ключи брать из окружения; `.env.example` — только шаблон, автоматической загрузки `.env` сейчас нет. При необходимости добавить её явно.
5. В адаптерах задать таймаут запроса (ориентир 60 секунд), ограниченные повторы и лимит ответа. Глобального принудительного таймаута в каркасе пока нет.
6. Реальный vision-провайдер обычно требует PNG/JPEG; заменить демонстрационные SVG настоящими кадрами поддерживаемого формата.
7. Запустить без `--demo`, проверить, что запросы и изображения действительно дошли до моделей.

Поставщик исходного видео: назначить отдельно. Поиск/скачивание, транскрибация, извлечение кадров, экспорт MP4, музыка и публикация в каркас не включены. Подготовка данных выполняется заранее.

## Что уже есть

Валидация контрактов, проверка таймкодов/длительности и точной цитаты, проверка файлов кадров, один цикл исправления, версии JSON, статусы, статический HTML, контрольные тесты.

## Что ещё не готово для защиты

Реальные модели и API, настоящее видео/кадры/транскрипт, оценка пропусков/ложных отказов критика, сетевые таймауты/бюджеты, репетиция и слайды. Автоматическая проверка не гарантирует обнаружение всех ошибок.
