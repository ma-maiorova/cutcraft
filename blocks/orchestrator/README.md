## Запуск сейчас

Из корня:

```bash
python3 main.py --demo
python3 -m unittest discover -s tests -v
```

## Запуск после подключения моделей

```bash
python3 main.py --catalog data/catalog.json --task "Объясни результат и ограничения"
```

Пока модели не подключены, live-команда намеренно завершается с NotImplementedError. Она не является готовым live-запуском.

Основная площадка — локальный компьютер, внешние модели через API. VM, база данных и запуск Claude Code/Codex CLI из приложения не требуются. GPU не нужен для локального кода при внешнем API.

## Передать команде

Воспроизводимый запуск, пример окружения без ключей, статусы и итоговую раскадровку. Проверить, что холодный старт у другого участника выполняется по README.
