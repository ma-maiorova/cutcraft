## Проверка

```bash
python3 -c 'import json; from pathlib import Path; from contracts import validate_catalog; from main import resolve_frames; p=Path("data/catalog.json").resolve(); c=validate_catalog(json.loads(p.read_text())); resolve_frames(c,p.parent); print("Каталог и пути корректны")'
```

Эта команда проверяет формат и наличие файлов, но не то, что текст совпадает с речью. Это сверяется на слух.

`python3 main.py --demo` берёт первые три фрагмента каталога (29.4 с) с фиксированными ответами. Демо проверяет, что каталог проходит через весь цикл, но не оценивает выбор сцен: для этого нужен живой запуск.

## Превью видео

```bash
pip install pillow
python3 scripts/render_short.py --video shtern_big_bang.mp4
```

Скрипт берёт последний запуск из `output/`, план из него и субтитры из `data/transcript.json`. Нужны ffmpeg и исходное видео: в Git оно не хранится, ссылка в `data/SOURCE.md`.
