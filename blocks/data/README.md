- [x] Сборка видео в Docker сама после живого запуска: план и `short.mp4` в одной папке ([ADR-0006](../../docs/adr/0006-shorts-in-container.md)).

## Проверка

```bash
python3 -c 'import json; from pathlib import Path; from contracts import validate_catalog; from main import resolve_frames; p=Path("data/catalog.json").resolve(); c=validate_catalog(json.loads(p.read_text())); resolve_frames(c,p.parent); print("Каталог и пути корректны")'
```

Эта команда проверяет формат и наличие файлов, но не то, что текст совпадает с речью. Это сверяется на слух.

`python3 main.py --demo` берёт первые три фрагмента каталога (29.4 с) с фиксированными ответами. Демо проверяет, что каталог проходит через весь цикл, но не оценивает выбор сцен: для этого нужен живой запуск.

## Видео

`short.mp4` собирается сам после живого запуска по итоговому плану (`scripts/render_short.py`, [ADR-0006](../../docs/adr/0006-shorts-in-container.md)): заголовок сцены сверху, субтитры из `data/transcript.json` снизу. Нужно исходное видео в папке `media/`, ссылка на него в `data/SOURCE.md`.

## Для защиты

Откуда видео и почему именно оно (разные кадры: схемы, фото, карта). Как получен транскрипт и что исправлено руками. Почему фрагменты режутся по фразам, а не по времени. Почему видео собирается кодом после агентного цикла, без моделей.
