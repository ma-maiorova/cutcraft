# Артём — данные и кадры

Ответственный: [Anelessar](https://github.com/Anelessar).

## Что менять

`data/catalog.json`, `data/frames/`. Код моделей не нужен. Инструкции этой папки — описание блока; данные лежат в `../../data/`.

## Задачи

- [ ] Выбрать одно видео на 1–3 минуты и обеспечить доступ команды к нему.
- [ ] Подготовить/сверить транскрипт с таймкодами.
- [ ] Собрать 6–8 кандидатов, чтобы монтажёр мог выбрать три и заменить неподходящий. Должна существовать комбинация 20–30 секунд.
- [ ] Для каждого извлечь минимум один настоящий PNG/JPEG-кадр; записать относительный путь.
- [ ] Сохранить формат `examples/catalog.json`; выставить реальную source_duration и assets_are_real только после замены карточек.
- [ ] Проверить границы start/end и доступность всех картинок. Передать источник и ограничения команде.

## Проверка отдельно

Из корня проекта:

```bash
python3 -c 'import json; from pathlib import Path; from contracts import validate_catalog; from main import resolve_frames; p=Path("data/catalog.json").resolve(); c=validate_catalog(json.loads(p.read_text())); resolve_frames(c,p.parent); print("Каталог и пути корректны")'
```

Техническая проверка не доказывает, что кадры/транскрипт соответствуют видео: сверить вручную. Текущий `--demo` завязан на первые три условных сцены, поэтому его не использовать для оценки нового контента; интегрировать реальный каталог с модулями команды.

## Передать

Каталог и картинки, источник видео, подтверждение ручной сверки. Никакого отдельного сервера/агента данных не требуется.
