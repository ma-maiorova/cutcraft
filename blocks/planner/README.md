## Что менять

`planner.py`, `prompts/planner.txt`. Исполняемый модуль остаётся в корне. Общий клиент API и настройку окружения согласовать с Кириллом.

## Задачи

- [ ] Уточнить prompt: выбрать ровно три существующих сегмента на 20–30 секунд, сохранить факты и оговорки.
- [ ] Подключить реальную текстовую модель в `build_plan(task, catalog, *, demo=False)`.
- [ ] Разобрать JSON-ответ модели, вернуть словарь по `examples/plan.json`.
- [ ] Реализовать `revise_plan(task, catalog, plan, review, *, demo=False)` — изменить затронутые сцены по замечаниям, сохранить scene_id и остальные сцены.
- [ ] Проверить создание и одну доработку на тестовом каталоге; затем на данных Артёма.
- [ ] Описать фактическую модель, ограничения, пример входа и ответа.

## Проверка отдельно

После подключения модели и настройки окружения по общей инструкции, из корня:

```python
import json
from contracts import validate_plan
from planner import build_plan, revise_plan
catalog = json.load(open("data/catalog.json"))
plan = validate_plan(build_plan("Объясни результат и ограничения", catalog), catalog)
# review получает от Галима или из согласованного контрольного примера
# updated = validate_plan(revise_plan(task, catalog, plan, review), catalog)
```

До подключения API можно использовать `demo=True` для проверки интерфейса, но ответы фиксированы. Пример review должен относиться именно к текущему плану.
