## Как работает

Критик получает задание, сцены плана с транскриптом своих фрагментов, неиспользованные фрагменты и кадры каждой сцены. Всё уходит одним запросом. Для каждой сцены он проверяет три вещи. Первая — заголовок: в нём только то, что сказано во фрагменте, оговорки на месте, длина не больше 10 слов. Вторая — кадр: на нём нет постороннего сюжета. Третья — связность: три сцены складываются в одну историю по заданию. Если сцена выпадает из истории, он предлагает замену из неиспользованных фрагментов.

SVG и файлы с неверной сигнатурой отклоняются до обращения к API. Ограничения: PNG, JPEG или WebP до 4 МБ, не больше 12 кадров на запрос.

## Что известно

- На реальном видео критик нашёл заголовок «После открытия реликтового излучения стало неприлично…», хотя во фрагменте про реликтовое излучение ничего не сказано. Монтажёр исправил сцену, повторная проверка прошла.
- Критик и монтажёр сейчас работают на одной модели. Отдельная модель для критика сделала бы проверку независимее, но из бесплатных моделей с изображениями стабильно отвечала только одна.
- Правила о длине заголовка и связности сцен в `prompts/reviewer.txt` добавлены при подготовке демо на реальном видео.
